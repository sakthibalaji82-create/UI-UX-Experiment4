# UI-UX-Experiment4

## Aim:
To design a low-fidelity wireframe diagram and screen-by-screen editing views in Balsamiq sketch style for a generic web/application workflow covering five essential screens:
## Algorithm:
1.Define Scope & User Flow: Identify the 5 core user-journey stages (Entry → Authentication → Navigation Hub → Catalog Discovery → Final Conversion) and map directional transitions (Get Started, Sign In, Browse, Checkout).

2.Initialize Project & Canvas Structure: Create a project structure (GenericApp.bmpr / .bmml mockups) using a browser/application container frame (760×560 / 800×600 layout) with Balsamiq-style sketch components (hand-drawn borders, [X] image placeholders, and low-fidelity typography).

3.Design Screen 1 — Welcome / Splash Screen:
Place a centered [X] app logo placeholder, welcome title, short value-proposition tiles, a primary Get Started → CTA button linked to Screen 2, a secondary Log In link, and onboarding step indicators.

4.Design Screen 2 — Login / Signup Screen:
Add a Login / Sign Up tab bar, Email Address and masked Password text inputs, Remember me checkbox, Forgot Password? link, primary Sign In button linked to Screen 3, and social sign-in buttons (Google, Apple).

5.Design Screen 3 — Home / Dashboard Screen:
Build a top navigation bar (Home, Browse, Orders, Contact, search box, notifications, user avatar), a hero banner with an [X] graphic placeholder and Explore Catalog → button, a 3-column summary card row (Active Orders, Saved Wishlist, Reward Points), and a 4-column featured categories grid.

6.Design Screen 4 — Content / Product Listing Screen:
Add a catalog header with a search bar and Cart (2) button, a filter & sort bar (All, Featured, Under $50, New, Sort: Most Popular), and a 3×2 product card grid where each card contains an [X] image box, title, price, star rating, and + Add to Cart button.

7.Design Screen 5 — Checkout / Contact / Final Action Screen:
Structure a step progress header and a 2-column layout: Contact & Shipping Information inputs + Payment Method radio options on the left, and an itemized Order Summary + primary Complete Order ✓ action button on the right.

8.Review, Edit & Export: Inspect element alignment, dimensions (X, Y, W, H), and screen links in the Property Inspector, then export the connected 5-screen flow diagram, the 5 screen-editing workspace views, and the .bmml source files.
